

# java-racingcar-precourse(자동차 경주 게임) 

## 기능 요구사항 목록

### 1. 사용자 입력 기능
- 경주할 자동차 이름 입력
    - 이름은 쉼표(`,`)로 구분
    - 각 이름은 최대 5자
- 시도할 횟수 입력
    - 자연수만 허용

### 2. 자동차 객체 및 상태 관리
- 자동차 이름을 저장하는 객체 생성
- 각 자동차의 전진 상태(횟수)를 관리
- 자동차 리스트를 통해 여러 자동차 상태 동시 관리

### 3. 전진 조건 로직
- 0~9 사이 랜덤 값 생성
- 랜덤 값이 4 이상이면 전진, 아니면 정지
- `camp.nextstep.edu.missionutils.Randoms.pickNumberInRange(0, 9)` 사용

### 4. 게임 실행
- 사용자가 입력한 횟수만큼 경주 반복
- 반복별 각 자동차 상태 출력
- 전진 여부에 따라 "-" 표시로 상태 업데이트

### 5. 우승자 결정
- 가장 많이 전진한 자동차 찾기
- 단독 우승자, 공동 우승자 모두 처리
- 쉼표(`,`)로 공동 우승자 구분
- 최종 우승자 출력

### 6. 예외 처리
- 사용자 입력 오류 시 `IllegalArgumentException` 발생 후 애플리케이션 종료

## 프로그래밍 요구사항 목록

### 1. 인덴트 관련
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
  - 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
  - 힌트: indent(인덴트, 들여쓰기) depth를 줄이는 좋은 방법은 함수(또는 메서드)를 분리하면 된다.
